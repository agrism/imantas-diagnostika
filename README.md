# Imantas Auto Diagnostika 🚗⚡

Moderna, ātra un uz konversiju orientēta mājaslapa uzņēmumam **"Imantas Auto Diagnostika"**.

> **Galvenais solījums:** Piebrauc, noskenējam kļūdas, iedodam kļūdu aprakstu — **tikai 50 EUR**, un tas viss **15 minūšu laikā**!

---

## 🌟 Galvenās funkcijas

1. **Ultra-ātrs un pārliecinošs Hero bloks**:
   - Skaidri izcelta cena: **50 € (Fiksēta cena)**
   - Skaidri izcelts laiks: **15 Minūtes (Uz vietas)**
   - Tūlītējas darbības pogas: Zvanīt tūlīt, WhatsApp pieteikums, Waze maršruts.
   - Live statusa indikators: *"Pieejams šodien Imantā • Bez iepriekšēja pieraksta nedēļām uz priekšu"*.

2. **15 Minūšu diagnostikas solis-pa-solim ceļvedis**:
   - `00-02 min`: Piebraukšana un pieslēgšanās pie OBD-II ligzdas.
   - `02-07 min`: Dziļā visu bloku skenēšana (Dzinējs, Kārba, ABS/ESP, Airbag, DPF u.c.).
   - `07-11 min`: Live Data rādījumu un parametru analīze.
   - `11-15 min`: Kļūdu izskaidrošana, atskaite uz WhatsApp/e-pastu un lampiņu nodzēšana.

3. **Kas iekļauts 50 € cenā**:
   - Visi auto vadības bloki (nevis tikai dzinējs).
   - Reāllaika datu analīze.
   - Kļūdu dzēšana.
   - Saprotams atšifrējums latviešu valodā.
   - Digitāla atskaite tālrunī.

4. **Interaktīvs Kļūdu simulatora bloks**:
   - Apskatāmi reāli kļūdu kodi (`P0420`, `P0300`, `P0171`, `DF025`, `ABS 01276`) ar skaidrojumu, ko tie nozīmē cilvēku valodā un kā ietaupīt naudu servisā.

5. **Salīdzinājuma tabula**:
   - Imantas Auto Diagnostika vs Parastais autoserviss vs Oficiālais dīleris.

6. **Interaktīva pieteikuma forma & WhatsApp ģenerators**:
   - Klients ievada auto marku, gadu un problēmu, un ar 1 klikšķi tiek sagatavota un atvērta WhatsApp ziņa.

7. **Mobilā piespraustā poga (Sticky bar)**:
   - Apakšā mobilajā tālrunī vienmēr pieejamas ātrās pogas: `📞 Zvanīt (50 €)` un `💬 WhatsApp`.

## 🚀 Kā palaist un lietot

### 1. Variants: Atvērt uzreiz pārlūkā (Bez instalēšanas)
Vienkārši atver failu `index.html` jebkurā interneta pārlūkprogrammā (Chrome, Safari, Firefox, Edge). Visi stili un skripti strādās nekavējoties.

### 2. Variants: Lokālais izstrādes serveris (Vite)
```bash
npm install
npm run dev
```
Pārlūkā atver: `http://localhost:5173`

### 3. Variants: Gatavs produkcijas būvējums (Build)
```bash
npm run build
```
Gatavie faili tiks ievietoti mapē `dist/`, ko var augšupielādēt uz jebkura hostinga (Vercel, Netlify, Hostinger, GitHub Pages utt.).
